# Engineer onboarding

Ledgerly engineers work across Europe and Asia.

## First week
- Get access to GitHub, AWS staging, the deploy tool and PagerDuty (read-only until you join the rota).
- Read the architecture overview and the coding standards.
- Pick a starter issue labelled `good first issue`.

## Buddy
Every new engineer gets an onboarding buddy from their team for the first month.

## Joining on-call
You join the on-call rota after your third month, starting as secondary for one month.

## Tools
We use Slack for chat, GitHub for code and issues, and PagerDuty for paging.
